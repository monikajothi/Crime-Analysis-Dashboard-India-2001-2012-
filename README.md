# 📊 Crime Analysis Dashboard (India 2001–2012)

## 🔍 Overview

This project presents an interactive Tableau dashboard analyzing crime patterns across India from 2001 to 2012. The goal is to uncover trends, identify high-crime regions, and provide meaningful insights using data visualization techniques.

## 📂 Dataset

* Source: Kaggle
* Dataset: Crime in India
* Records: 9018 rows
* Features: 33 columns
* Covers multiple crime categories across Indian states over 12 years

## 🎯 Objectives

* Analyze crime trends over time
* Identify states with high crime rates
* Compare different crime categories
* Enable interactive filtering for better insights

## 🛠️ Tools Used

* Tableau (Data Visualization)
* Excel / CSV Dataset

## 📁 Project Structure

* `dashboards/` → Tableau Workbook (.twb)
* `images/` → Dashboard screenshots
* `docs/` → Project presentation

## 📊 Key Insights

* Certain states consistently show higher crime rates over the years
* Crime trends vary significantly across categories
* Some crime types show increasing trends over time
* Regional patterns help identify high-risk zones

## 🚀 How to Use

1. Download the `.twb` file from `dashboards/`
2. Open using Tableau Desktop or Tableau Public
3. Explore filters and interactive dashboards
